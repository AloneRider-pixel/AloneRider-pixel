# Profile claim policy

The profile is an index of engineering work, not a benchmark report.

Quantitative claims are allowed only when the surrounding text identifies an evidence source, design target, benchmark, dataset, or commit. Project capability statements should link to code, tests, architecture, or evaluation documentation.

Profile CI performs a lightweight guard against metric-like claims such as percentages and latency multiples so unsupported numbers do not silently become part of the public profile.
