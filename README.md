## Engineering Principles

- **Reliability:** design for failure, retries, idempotency, health checks, and graceful degradation.
- **Security:** keep secrets out of source control, validate untrusted input, and make authorization explicit.
- **Observability:** make latency, errors, traces, costs, and system state measurable.
- **Evaluation:** distinguish demonstration metrics from reproducible benchmark results.
- **Maintainability:** prefer clear boundaries, typed interfaces, focused modules, and documented trade-offs.
